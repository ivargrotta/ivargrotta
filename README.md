# ivar. — Ivar Grøtta

Statisk portfolio-nettside (HTML/CSS/JS, ingen byggesteg).

- `index.html` – innhold og struktur
- `styles.css` – design og animasjoner
- `script.js` – «ivar.»-identiteten (to prikker som blir til ordmerket), forsiden uten scroll, rommene Arbeid, Kontakt, Tid (urverk-universet bak klokken) og Kart (Oslo sentrum bak koordinatene), mapper med galleri, cursor og animasjoner

Åpne `index.html` i nettleseren, eller publiser med GitHub Pages (Settings → Pages → Deploy from branch).

Kartet bruker [MapLibre GL JS](https://maplibre.org) 4.7.1 (lagt i `vendor/maplibre-gl/`, BSD-lisens) og åpne kartfliser fra [OpenFreeMap](https://openfreemap.org) basert på © OpenStreetMap-bidragsytere.
