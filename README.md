# ivar. — Ivar Grøtta

Statisk portfolio-nettside (HTML/CSS/JS, ingen byggesteg).

- `index.html` – innhold og struktur
- `styles.css` – design og animasjoner
- `script.js` – «ivar.»-identiteten (to prikker som blir til ordmerket), forsiden uten scroll, rommene Arbeid, Kontakt og Tid (urverk-universet bak klokken), mapper med galleri, cursor og animasjoner

Åpne `index.html` i nettleseren, eller publiser med GitHub Pages (Settings → Pages → Deploy from branch).
